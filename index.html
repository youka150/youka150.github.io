SELECTED WORK / 01
本科毕业设计 · 2026.04

InsightAI 2026.

从社区里的声音，读懂人与趋势。

THE QUESTION

谁在影响讨论，
什么正在成为趋势？

面向华为开发者社区与昇腾生态社区，InsightAI 将社区内容、用户互动和 AI 分析整合在同一套工作流里，帮助运营、产品、管理与数据工程角色理解社区。

项目类型
本科毕业设计 / 多社区智能分析系统
前端体验
Next.js 15 · React 19 · Framer Motion
数据与计算
Python FastAPI · PostgreSQL
核心方法
PageRank · LDA · KMeans · LLM
THREE WAYS TO UNDERSTAND A COMMUNITY
01

从关系，理解用户。

+

把回复与评论关系构建成有向加权网络，结合 PageRank、中心性和内容指标理解用户影响力，再通过 KMeans 聚类描绘不同群体。

关系网络 · 影响力榜单 · 群体画像
02

从内容，发现变化。

+

以 LDA 主题建模提取社区讨论的线索，用时序趋势与 Z-score 异常检测观察波动，让热点、反馈和潜在需求有迹可循。

主题提取 · 情感汇总 · 趋势异常检测
03

让 AI 分析过程可见。

+

创意趋势分析采用规划、搜索、总结、反思与补充的分阶段流程。SSE 流式呈现分析进展，让等待变成可理解的过程，并支持报告导出。

Agent 工作流 · SSE 流式反馈 · 结构化报告
FROM DATA TO INSIGHT

A NOTE ON THE PROCESS

好的分析，也需要理解自己的边界。

这次探索不仅关乎生成结论，也关乎结论从何而来。文档中记录了启发式评分的偏差、大规模网络计算的开销，以及 LLM 输出的可追溯性问题。下一步是加强指标验证、语义理解与可复现评估。

依据毕业设计系统介绍文档整理 · 界面为重绘示意，不代表实际运行数据。
